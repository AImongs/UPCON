## 3. 파이프라인

```
원본 ─ffmpeg(rawvideo 파이프)─▶ [Producer 스레드] 청크 BMP ─▶ ncnn-vulkan 2× (-v 로 실제 완료 프레임 집계)
     ─▶ [Feeder 스레드] ffmpeg 인코더 stdin (image2pipe PNG) ─▶ H.264 MP4 + 원본 오디오 (copy / 비호환 시 AAC) ─▶ 파일명_2x.mp4
```
- 디코드 / 업스케일 / 인코드 3단계 중첩. 청크 크기는 `temp_budget_mb`(기본 1.5 GB) 에서 역산 (480p 120f, 1080p 105f).
- 인코더: **NVENC/AMF/QSV 자동 감지** (실제 테스트 인코딩으로 확인) → 없으면 libx264. 4K 에서 x264 는 CPU 를 독점해 ncnn 까지 느려짐 (135s → NVENC 121s → 3단계 중첩 105s).
- 디스크: 시작 전 임시 + 출력 예상 용량 계산, 부족하면 한국어 안내 후 중단 (pytest 로 검증).
- 취소: 자식 프로세스 3종 종료 → 임시 폴더·미완성 결과 삭제 → UI 복구 (pytest + UI 스모크로 검증).
- 원본 파일은 읽기 전용으로만 접근, 결과는 `이름_2x.mp4`, 중복 시 `이름_2x (2).mp4`.

## 6. 품질 평가 (실제 AI 생성 영상: Seedance 2.0/2.5, Higgsfield)

객관 지표 (48프레임, bicubic 2× 대비):

| 클립 | 프레임 간 변화량 비율 (1.0 = 원본과 동일) | 정적 영역 flicker (/255) | 선명도 비율 |
|---|---|---|---|
| 얼굴 (hf1, 480p) | 1.08 | 0.34 | 1.86 |
| 도심/간판 (480p) | 1.06 | 1.37 | 1.53 |
| 액션/안개 (480p) | 1.04 | 0.85 | 1.31 |
| 고속도로/번호판 (1080p→4K) | 1.10 | 0.86 | 2.84 |

→ 업스케일러가 추가하는 프레임 간 변화는 4~10% 로 작고, 정적 영역 flicker 는 1/255 안팎 (육안 감지 불가 수준).

육안 평가 (`tests/out/quality/cmp_*.jpg`, 왼쪽 bicubic / 오른쪽 UPCON, 연속 3프레임):

| 항목 | 평가 |
|---|---|
| 얼굴 | 눈·입술 윤곽 뚜렷, 프레임 간 일관. **피부 미세 질감이 다소 매끈해짐** (모공 수준 디테일 손실, 왁스 느낌은 약함) |
| 머리카락 | 가닥 경계 선명해짐, 뭉침 없음 |
| 피부 | 위와 같음. `wdn`(질감 유지) 모델이 더 자연스러울 수 있어 옵션으로 제공 |
| 옷 | 정장 질감·넥타이 무늬 개선 |
| 배경 | 벽돌·창문 격자 복원 좋음. **자동차 그릴 메쉬처럼 아주 미세한 반복 패턴은 뭉개짐** |
| 글자 | 간판 한글, 번호판 숫자 확실히 선명 (오독 없음) |
| 움직이는 물체 | 모션 블러는 블러대로 유지 (억지 선명화 없음) |
| 카메라 이동 | 이동 중 배경 떨림 없음 |
| flicker | 정지/이동 장면 모두 육안 식별 불가 |
| 전체 자연스러움 | "선명한 원본" 느낌. 가는 전선 등 고대비 얇은 선이 살짝 과선명 |

**AI 드라마 사용 가능 여부: 480p → 960p 용도로 충분히 사용 가능.** 클로즈업 얼굴에서 피부 질감이 매끈해지는 점이 유일한 눈에 띄는 단점이며, 이는 확산 기반 모델(클라우드 FlashVSR / 로컬 SeedVR2)이 더 잘하는 영역.

## 9. 최종 판단

**Real-ESRGAN (general-x4v3, ncnn-vulkan) 을 UPCON 기본 로컬 엔진으로 계속 사용하는 것을 추천한다.**

근거: (1) RTX 5060 에서 480p 1분 = 2분, VRAM 0.25 GB 로 저사양 GPU 까지 커버 (2) CUDA/PyTorch 없이 30 MB 실행파일 + 15 MB 모델로 배포 가능 (3) 실측 flicker 가 무시할 수준 (4) 라이선스 허용적.

한계와 대안: 얼굴 피부 질감 손실, 미세 반복 패턴 뭉개짐 → 고화질이 필요할 때 클라우드 FlashVSR(STEP 4) / 로컬 SeedVR2(Tier 2, 12 GB+ 권장) 로 보완. 1080p→4K 는 1분당 9.4분으로 느리므로 UI 에 예상 시간을 표시하고 긴 4K 작업은 클라우드를 권할 필요.
